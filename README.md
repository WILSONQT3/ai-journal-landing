# MindLog — AI-Powered Journaling Landing Page

A modern, responsive landing page wireframe for an AI-powered journaling application called **MindLog**. This project showcases a clean, dark-themed SaaS landing page with all the essential sections: hero, features, testimonials, CTA, and footer.

## Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Modern styling with CSS variables, grid, flexbox, animations, and responsive design
- **JavaScript** — Interactive elements (mobile nav toggle, smooth scroll, form handling, scroll animations)

## Features

- **Hero Section** — Bold headline with gradient text, animated mockup card, social proof stats
- **Features Grid** — 6 feature cards with hover effects and scroll-triggered fade-in animations
- **Testimonials** — 3 testimonial cards with star ratings, author info, and staggered animations
- **CTA Section** — Email capture form with validation feedback, floating emoji animations
- **Footer** — Multi-column footer with brand info and link groups
- **Responsive Design** — Fully adaptive from desktop to mobile (768px and 480px breakpoints)
- **Mobile Navigation** — Hamburger menu with smooth open/close animation
- **Smooth Scrolling** — Anchor link navigation with smooth scroll behavior
- **Scroll Animations** — Intersection Observer-based fade-in for feature and testimonial cards

## Setup

1. Clone or download the repository.
2. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge).
3. No build steps or dependencies required.

## Project Structure

```
├── index.html      # Main HTML file
├── styles.css      # All styles
├── app.js          # JavaScript interactions
└── README.md       # Project documentation
```

## Customization

- **Colors** — Edit CSS variables in the `:root` block of `styles.css`
- **Content** — Update text, images, and links directly in `index.html`
- **Animations** — Adjust timing and delays in `app.js` and `styles.css`
